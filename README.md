## 자동 실행

`Daily research and website` 작업이 매일 한국시간 08:00/16:00에 해당하는 UTC 23:00/07:00에 실행됩니다. GitHub 예약은 지연될 수 있으므로 정시 도착을 보장하지 않습니다. 예약은 컴퓨터가 꺼져 있어도 GitHub 서버에서 실행됩니다.

기존 ChatGPT 예약 브리핑은 수정하지 않았습니다. 이 사이트의 독립 수집 결과와 ChatGPT 보고서는 동일하지 않을 수 있습니다. GitHub Actions는 공식 피드·등록처의 자료를 저장합니다. 한국어 분석을 보강해 이 저장소에 반영하는 별도 앱 예약도 08:00/16:00에 설정했습니다. 이 보강 작업은 현재 컴퓨터와 앱이 실행 중이어야 합니다. 컴퓨터가 꺼져 있어도 실행되는 GitHub 수집과 구분해야 합니다. 외부 AI API나 유료 서비스를 이 저장소에서 자동 결제하지 않습니다.

## 수집 범위

현재 어댑터: Eli Lilly 공식 뉴스·실적 RSS, 공식 IR 행사 RSS, ClinicalTrials.gov 대사/심혈관/안과 API. 2026-11-04 GitHub 실행에서 세 임상 API는 성공했으며 Lilly 두 피드는 HTTP 403으로 거부되었습니다. 접근 제한을 우회하지 않으며 실패 상태를 화면에 노출합니다. 피드에 없는 원문·컨콜 전문, 모든 글로벌 기업, X·LinkedIn·채용 전체를 완전히 수집하지는 못합니다. Novo Nordisk와 소셜·채용 등의 미연결 출처는 매 회차 coverage에 표시합니다. 초기 연결 확인용 Novo 공식 실적 1건과 임상 스냅샷이 실제로 저장되었습니다. 한국어 레지스트리 라벨과 원문 발췌는 AI 분석으로 표시하지 않습니다.

원문에 정확한 게시 시간이 없으면 임의의 시간을 만들지 않습니다. 임상 등록처 갱신은 새 임상 성공 발표가 아니며, 결과 해석에는 원문 검토가 필요합니다.

## 보관·중복·백업

`public/data/YYYY-MM-DD-AM.json` 및 `PM.json`, `index.json`에 저장합니다. 동일 사건·본문은 회차 간 중복 제거하고 달라진 본문은 버전으로 남깁니다. 사이트 기본 보기는 최신 버전이며 변경 이력 버튼으로 이전 자료도 확인할 수 있습니다.

48시간 겹침 구간을 재점검합니다. 공급원별 실패·미연결·정상 0건을 구분합니다. 수집이 실패해도 오류가 보이는 부분 보고서를 발행하고, 작업 실행은 실패 상태로 남깁니다. Git 변경 이력과 30일 Actions 산출물을 백업으로 유지합니다. 둘 다 GitHub에 있으므로 독립적인 오프사이트 백업은 아닙니다. 저장소 ZIP을 정기 다운로드해 별도 보관하는 것을 권장합니다.

## 실행과 검증

Node.js 22 이상. 의존성 설치 없이 `npm test`, `npm start`로 검증·로컬 실행할 수 있습니다. 웹 화면은 `public/`, 수집과 정규화는 `scripts/`, 설정은 `sources.json`입니다. `node scripts/collect.mjs YYYY-MM-DD AM --dry-run`으로 DB 없이 수집하고 `node scripts/build-archive.mjs YYYY-MM-DD AM`으로 아카이브에 반영합니다.

이 저장소와 사이트는 공개됩니다. 비밀번호·키·개인 투자정보·비공개 자료는 저장하지 마세요. 외부 문서는 데이터로만 다루고 문서 속 지시문을 실행하지 않습니다. 소스 내용을 HTML로 실행하지 않으며 출처 링크는 HTTPS만 허용합니다.
